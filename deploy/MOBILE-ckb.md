# بەکارهێنانی یاوەر لە مۆبایل

یاوەر وێب‌ئەپە؛ APK یان ئەپی دامەزراوی Android/iPhone نییە. مۆبایل لە ڕێگەی وێبگەڕەوە بە سێرڤەری کۆمپیوتەری کلینیک پەیوەست دەبێت. کۆمپیوتەر دەبێت کار بکات و نەچێتە Sleep.

## ١. هەمان تۆڕ

کۆمپیوتەری Windows و مۆبایلەکە بە هەمان تۆڕی تایبەتی کلینیک پەیوەست بکە. تۆڕی میوانان یان Client Isolation دەتوانێت پەیوەندی بگرێت. ئەم ڕێگایە بۆ دەرەوەی کلینیک نییە.

## ٢. سێرڤەری ناوخۆیی HTTPS

- بۆ کۆمپیوتەرەکە IPێکی ناوخۆیی جێگیر دابنێ؛ بۆ نموونە `192.168.1.50`. ئەمە تەنها نموونەیە، IPی ڕاستەقینە بە `ipconfig` ببینە و لە ڕاوتەر DHCP reservation ڕێک بخە.
- Node.js 24+ پێویستە؛ پاکێجی Windows-x64 runtimeی لەخۆ گرتووە، بەڵام ZIPی source-code تەنها کۆدە و Node.js دەبێت بە جیا دامەزرێنرێت.
- Caddy لە سەرچاوەی فەرمی https://caddyserver.com/docs/install دامەزرێنە و لە PATH بەردەستی بکە.
- پەنجەرەی پێشووی Start-Clinic.cmd دابخە. لە PowerShell، لە بوخچەی پڕۆژەکە ئەم فرمانە جێبەجێ بکە (IPەکە بگۆڕە):

```powershell
.\deploy\Windows-LAN.ps1 -ClinicHost 192.168.1.50
```

Windows Firewall تەنها بۆ پۆرتی TCP 443 لە Private network و Local subnet ڕێگە بدات؛ پۆرتی Node/3000 بە ئامێرەکانی تر مەکەرەوە و هیچ port-forwardingێک بۆ ئینتەرنێت مەکە. ئەگەر سیاسەتی PowerShell ڕێگە بە script نادات، پسپۆڕی کۆمپیوتەرەکە با script و سیاسەتی ڕێگەپێدراوی کلینیکەکە بپشکنێت.

## ٣. بڕوانامەی متمانەپێکراو

Caddy بڕوانامەی تایبەتی بۆ تۆڕی ناوخۆ دروست دەکات. فایلە گشتییەکەی `root.crt` لە data directoryی Caddy بدۆزەوە (`caddy environ` شوێنەکە پیشان دەدات؛ بە گشتی `pki/authorities/local/root.crt` لەژێر data directoryیەکەدایە). تەنها `root.crt` بە شێوەیەکی پارێزراو بگوازەوە؛ فایلەکانی key یان تەواوی بوخچەی Caddy مەگوازەوە.

- Android: لە Settingsی Security/Encryption & credentials هەڵبژاردەی Install a certificate → CA certificate بەکاربهێنە. ناوی menu بەپێی ئامێر دەگۆڕێت.
- iPhone: بڕوانامەکە وەک profile دامەزرێنە، پاشان لە Settings → General → About → Certificate Trust Settings متمانەی ڕەگەکە چالاک بکە.

تەنها CAی کلینیکەکەت کە سەرچاوەکەی دەزانیت دامەزرێنە. ئاگادارکردنەوەی بڕوانامە لە وێبگەڕ تێمەپەڕێنە؛ ئەگەر هەڵەیەک هەیە، پەیوەندی و بڕوانامەکە با پشکنین بکرێن. ئەم ڕێکخستنەی مۆبایل و Windows لە ئامێرەکانی کلینیک هێشتا جێبەجێ نەکراوە.

## ٤. کردنەوە لە مۆبایل

لە Chrome یان Safari ئەم ناونیشانە بکەرەوە (بە IPی ڕاستەقینەی خۆت):

```
https://192.168.1.50
```

بە هەژماری تایبەتی خۆت بچۆ ژوورەوە. لە menuی وێبگەڕ، Add to Home Screen هەڵبژێرە بۆ دەستگەیشتنی خێرا. ئەمە shortcutە؛ سیستەمەکە offline نییە و هەر پێویستی بە سێرڤەری کلینیک هەیە. پێش زانیاری ڕاستەقینە، تۆمار و پارەدانێکی تاقیکردنەوە بپشکنە و دڵنیابە لە پاراستنی پەیوەندی و پاشەکەوت.

بۆ پەیوەندی لە دەرەوەی کلینیک، پێویست بە دامەزراندنێکی جیاواز و پەیوەندی پارێزراوە؛ IPی ناوخۆیی بە ئینتەرنێت ناگات.
