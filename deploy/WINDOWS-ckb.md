# وەشانی بەرنامەی Windows بە Setup.exe

١. پێش نوێکردنەوە، لە ڕێکخستنەکانی سیستەم پاشەکەوتێک دابگرە و هەموو پەنجەرەکانی یاوەر و سێرڤەرە کۆنەکە دابخە.
٢. `Yawar-Setup.exe` دامەزرێنە. Node.js لەناویدایە؛ پێویست بە ئینتەرنێت بۆ کاری ڕۆژانە نییە. Microsoft Edge یان Chrome دەبێت لە Windows هەبێت.
٣. ئایکۆنی **Yawar Clinic** لە Desktop بکەرەوە. سیستەمەکە لە پەنجەرەی تایبەت دەکرێتەوە؛ پەنجەرە ڕەشەکە پیشان نادرێت.
٤. ئەگەر پێشتر بە فایلی چاککراوی دەستپێکردن کارت کردووە، داتاکە لە `%LOCALAPPDATA%\YawarClinic\data` بە خۆکار بەکاردەهێنرێتەوە. ئەگەر داتاکەت لە بوخچەیەکی ترە، لە Start Menu → Yawar Clinic → **Choose existing clinic data** ئەو بوخچەیە هەڵبژێرە کە `clinic.sqlite`ی تێدایە؛ هەموو پەنجەرەکان پێش ئەوە دابخە. هیچ داتایەک ناگوازرێتەوە و ناسڕێتەوە.
٥. دوای کردنەوە بە هەژماری خۆت بچۆ ژوورەوە. ئەگەر لەبری هەژمارە پێشووەکان فۆرمی دامەزراندنی یەکەم جار دەرکەوت، داتا نوێ تۆمار مەکە؛ سەرەتا بوخچەی داتای پێشووت بە هەڵبژاردەی سەرەوە دیاری بکە.

سڕینەوەی بەرنامەکە داتای کلینیک ناسڕێتەوە. وەشانی Desktop بۆ هەمان کۆمپیوتەرە؛ بۆ سێرڤەری هەمیشە کراوەی مۆبایل/LAN ڕێنمایی خوارەوە بەکاربهێنە. لەبیرم مەکە بۆ ٣٠ ڕۆژ هەژمارەکە کراوە دەهێڵێتەوە؛ داخستنی پەنجەرە هەژمارەکە ناگاتە دەرەوە. دوگمەی دەرچوون، بەسەرچوونی ماوە یان گۆڕینی وشەی نهێنی/ڕۆڵ هێشتا پێویستی بە چوونەژوورەوەی نوێ هەیە. Setupەکە واژۆی دیجیتاڵی نییە و لەم ژینگەی Linuxەدا دروست و پشکنراوە؛ دامەزراندنی ڕاستەقینە و ئایکۆن و پەنجەرەکە لە Windowsی کلینیک پێویستیان بە پشکنین هەیە.

# دامەزراندنی یاوەر لە Windows

## یەک کۆمپیوتەر (ڕێگای سەرەکی)

١. ئەگەر پاکێجی Windows-x64 بەکاردەهێنیت، فایلە ZIPەکە Extract بکە؛ Node.jsی پێویست لەناویدایە. ئەگەر تەنها کۆدی پڕۆژەکەت هەیە، Node.js 24 یان نوێتر لە https://nodejs.org دامەزرێنە.
٢. تەواوی بوخچەی پڕۆژەکە لە شوێنێکی هەمیشەیی دابنێ، بۆ نموونە `C:\Yawar`. لە OneDrive یان بوخچەیەکی هاوبەشی تۆڕ دایمەنێ.
٣. `Start-Clinic.cmd` بە دوو کلیک بکەرەوە. وێبگەڕ دەکرێتەوە؛ پەنجەرەی سێرڤەر مەخە.
٤. لە یەکەم جاردا ناوی کلینیک و هەژماری بەڕێوەبەر دروست بکە. وشەی نهێنی لانیکەم ١٢ پیت بێت. هەژماری ئامادە یان وشەی نهێنی بنەڕەتی نییە.
٥. لە ڕێکخستنەکان هەژماری جیا بۆ هەر پزیشک و کارمەندێک دروست بکە.
٦. پێش تۆماری ڕاستەقینە، بە نەخۆشێکی تاقیکردنەوە مەوعید، چارەسەر، پارەدان، چاپ و گەڕاندنەوەی پاشەکەوت بپشکنە.

ئەم دۆخە تەنها لە هەمان کۆمپیوتەر کار دەکات؛ زانیاری لە ئینتەرنێت بڵاو ناکاتەوە. بەکارهێنانی HTTP لە لووپباکی هەمان ئامێرە؛ بۆ ئامێری تر دۆخی LANی خوارەوە بەکاربهێنە.

## پاشەکەوت

سێرڤەر لە کاتی کارکردنیدا پاش دەستپێکردن و هەر ٢٤ کاتژمێرێک پاشەکەوتێکی پشکنراو دروست دەکات و دوایین ١٤ کۆپی دەپارێزێت. لە ڕێکخستنەکان دۆخی دوایین پاشەکەوت دەبینیت. `Backup-Clinic.cmd` پاشەکەوتی دەستی دروست دەکات؛ ڕێکخستنەکانیش داگرتنی کۆپی دەدات.

فایلەکان لە `data\backups` دان. ئەمە لە هەمان دیسکە و جێگای پاشەکەوتی دەرەکی ناگرێتەوە. کۆپی بگوازەوە بۆ دیسکێکی دەرەکیی کۆدکراو؛ دیسکی Windows بە BitLocker بپارێزە. `BACKUP_DIR` دەتوانێت شوێنی پاشەکەوت بگۆڕێت. بوخچەی `data` بە تەواوی زانیاری نەخۆشە؛ بڵاوی مەکەرەوە.

بۆ گەڕاندنەوە، سەرەتا هەموو سێرڤەرەکانی کلینیک دابخە، پاشان لە Terminalی بوخچەی پڕۆژەکە:

```
runtime\node.exe scripts/restore.js "D:\ClinicBackup\yawar-backup.sqlite" --server-stopped
```

سیستەمەکە کۆپییەکی داتای پێشوو دەپارێزێت و هەموو دانیشتنەکانی چوونەژوورەوە دادەخات. پاشان `Start-Clinic.cmd` بکەرەوە. پێش پشتبەستن بە پاشەکەوت، ئەم ڕەوتە بە داتای تاقیکردنەوە بپشکنە.

## چەند ئامێر لە ناوخۆی کلینیک (ئارەزوومەندانە)

ئەگەر پێویستە چەند کۆمپیوتەر یان تابلێت بەکاربهێنیت، پسپۆڕی تۆڕ دەتوانێت:

- IPێکی ناوخۆیی جێگیر بۆ کۆمپیوتەری سەرەکی دابنێت و تەنها تۆڕی تایبەتی کلینیک لە Windows Firewall ڕێگەپێبدات؛ هیچ port-forwardingێک بۆ ئینتەرنێت نەکات.
- Caddy لە سەرچاوە فەرمییەکە دامەزرێنێت. سێرڤەری پێشوو دابخات و `deploy\Windows-LAN.ps1 -ClinicHost 192.168.1.50` بە IPی ڕاستەقینەی کلینیکەکە جێبەجێ بکات.
- بڕوانامەی ڕەگی تایبەتی Caddy لە هەر ئامێرێکی ڕێگەپێدراو دابمەزرێنێت و HTTPS بپشکنێت. بە هیچ شێوەیەک ئاگادارکردنەوەی بڕوانامەی وێبگەڕ تێنەپەڕێنێت.

Node لە لووپباک دەمێنێتەوە؛ Caddy پەیوەندییە ناوخۆییەکان کۆد دەکات. ئەم دامەزراندنەی Windows لێرە جێبەجێ نەکراوە؛ پێویستە لە کۆمپیوتەری کلینیک بپشکنرێت.

## دەستپێکردنی خۆکار لە Windows

بۆ دەستپێکردن لەگەڵ چوونەژوورەوەی بەکارهێنەری Windows، shortcutێک بۆ `Start-Clinic.cmd` دروست بکە و لە بوخچەی Startupی بەکارهێنەر دایبنێ (Win+R، پاشان `shell:startup`). کۆمپیوتەر نابێت بچێتە Sleep لە کاتی کاری کلینیک. بۆ LAN، پسپۆڕەکە دەبێت هەردوو پرۆسەی Node و Caddy بە خزمەتگوزاری یان Task Scheduler بەڕێوەببات.

## ئەگەر وشەی نهێنی بەڕێوەبەرت لەبیر چوو

ئەگەر بەڕێوەبەرێکی تر هەیە، دەتوانێت لە ڕێکخستنەکان وشەی نهێنیت نوێ بکاتەوە. ئەگەر نییە، خاوەنی کۆمپیوتەرەکە سەرەتا هەموو سێرڤەرەکانی کلینیک دادەخات و لە Terminalی بوخچەی پڕۆژەکە دەنووسێت:

```
runtime\node.exe scripts/reset-admin.js admin --server-stopped
```

`admin` بە ناوی بەکارهێنەری ڕاستەقینە بگۆڕە. وشەی نهێنی نوێ لە Terminal داوا دەکرێت و پیشان نادرێت؛ لە chat یان فایلێکی ئاسایی مەینووسە. هەموو دانیشتنەکان دادەخرێن. ئەمە تەنها بۆ کەسی مۆڵەتپێدراو و کۆمپیوتەری پارێزراوی کلینیکە.

## چارەسەری Cannot find module / scripts\launch.js

فایلی نوێی `Start-Clinic.cmd` خۆی دۆخی ناتەواوی فایلەکان دەناسێتەوە. ئەگەر Explorer تەنها CMDەکە لەناو ZIP دەربهێنێت، سیستەمەکە بە خۆکار لە GitHub دادەبەزێنێت و لە `%LOCALAPPDATA%\YawarClinic\app-launcher-v4` دادەنێت؛ داتای ئەم دامەزراندنە لە `%LOCALAPPDATA%\YawarClinic\data` دەمێنێتەوە. یەکەم جار ئینتەرنێت پێویستە؛ جارەکانی دواتر لە کۆپییە هەڵگیراوەکە کار دەکات. داتای دامەزراندنی پێشوو لە بوخچەیەکی تر ناگوازێتەوە و ناسڕێتەوە. ئەگەر داتای ڕاستەقینەت لە شوێنێکی تر هەیە، ڕێڕەوی DATA_DIR بە دروستی دیاری بکە یان هەمان بوخچەی تەواوی پێشوو بەکاربهێنە.

## وەشانی ٤ — سەردان، نەقد، قەرز و قیست

لە بەشی **چارەسەری نوێ** نەخۆشی پێشوو هەڵبژێرە یان **نەخۆشی نوێ** لە هەمان فۆرم بنووسە. جۆری چارەسەر و نرخی دیاری بکە، پاشان لە ژمارەی ددان بدە. دەتوانیت بۆ هەمان ددان چەند جۆر چارەسەر زیاد بکەیت؛ × یان دووبارە کلیک لە هەمان جۆر لای دەبات. R ڕاستی نەخۆشە و L چەپی نەخۆشە؛ ژمارەی تەواوی FDI دەپارێزرێت.

جۆری پارەدان **نەقد، قەرز یان قیست** هەڵبژێرە. بۆ قیست، پارەی سەرەتایی، ژمارەی قیست و بەرواری یەکەم دان دیاری بکە و خشتەی مانگانە دروست بکە. کۆی قیستەکان دەبێت یەکسان بێت بە پارەی ماوە. لە بەشی **قیستەکان** پارەی هەر قیستێک تۆمار بکە؛ حسابی نەخۆش و چارەسەرەکان بە خۆکار نوێ دەبنەوە. گەڕاندنەوەی پارە و ڕاستکردنەوەی نرخ بە هەڵبژاردەی بەڕێوەبەر بە تۆماری مێژوو ئەنجام دەدرێن و خشتەکەش ڕێکدەخرێتەوە.

**پێش نوێکردنەوە backup دابگرە.** سێرڤەر لە یەکەم نوێکردنەوەدا کۆپییەکی `before-v4-*.sqlite` لە بوخچەی داتاکەت دەپارێزێت؛ ناسڕێتەوە و داتاکەت ناگوازێتەوە. ئەگەر لەبری تۆمارە پێشووەکان فۆرمی یەکەم دامەزراندن دەرکەوت، تۆماری نوێ دروست مەکە و بوخچەی داتای پێشوو بە **Choose existing clinic data** دیاری بکە. دەستگەیشتن بە هەژمار لە کۆمپیوتەری هاوبەش بۆ ٣٠ ڕۆژ تەنها کاتێک هەڵبژێرە کە کۆمپیوتەرەکە بۆ کارمەندە ڕێگەپێدراوەکان پارێزراوە.

بۆ قەرزە پێشووەکان لە **نەقد و قەرز** دوگمەی **بە قیستکردن** هەڵبژێرە؛ ژمارە و بەروار دیاری بکە. نەخۆش و چارەسەرەکە دووبارە تۆمار ناکرێتەوە، تەنها پلانی پارەدانی ماوە زیاد دەکرێت.
